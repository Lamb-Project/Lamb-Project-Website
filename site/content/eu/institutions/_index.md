LAMBek AA sortzailea instituzioaren ikaskuntza-ingurunera ekartzen du. Irakasleek eta ikasleek laguntzaileak eta jarduerak LMSaren bidez erabiltzen dituzte, eta instituzioak kudeatzen ditu sarbidea, eredu-hornitzaileak eta ikastaroko datuak tratatzeko baldintzak.

**GNU GPL v3 lizentziapeko software librea** da, eta iturburu-kodea eskuragarri dago lizentziaren arabera aztertu, egokitu eta partekatzeko. LTIk jarduerak Moodle eta Canvas bezalako LMS plataformekin konektatzen ditu. Aukerako Moodle konektoreak, gainera, LAMB LEGATUSi (irakasleentzako agenteari) ikastaroko eduki eta jarduera baimenduetarako sarbidea ematen dio web-zerbitzu estandarren bidez, Moodle-pluginik instalatu gabe.

## Zure AAren azken kilometroa {#the-last-mile-for-your-ai}

Baliteke zure instituzioak bere ereduak dagoeneko exekutatzea edo bere eskakizunak betetzen dituen hornitzaile bat erabiltzea. LAMBek ikasle bakoitzari haietarako sarbidea ematen dio, eskolak eta irakasleak ezarritako arauen arabera: irakasleen kuotak, ikasle bakoitzeko mugak, ordutegiak eta erabilera zenbatzen zaion gako pertsonal bat. 0.8 bertsioan, horrek LLM access jarduerak hartzen ditu, ikasleen tresna propioetarako. [Zure AAren azken kilometroa →](/eu/institutions/ai-governance/)

## Gobernantza eta hornitzaile-hautaketa {#governance-and-provider-choice}

Erabaki nork sor eta erabil ditzakeen AA jarduerak, zein sorkuntza- eta embedding-zerbitzu onesten diren, eta nola atzi daitezkeen edukiak eta elkarrizketak. Erabaki horiei esker, LAMB instituzioak pribatutasunaren, datuen babesaren (DBEO) eta AAren gobernantzaren arloan egiten duen lanaren parte bihurtzen da. Araudia betetzea instituzioaren politiken eta hedapenaren araberakoa da, baita softwarearen konfigurazioaren araberakoa ere.

Aukeratu onartutako hornitzaileen artean, norberak ostatatutako inferentzia, hodeiko zerbitzuak edo zure politikarako egokia den konbinazio bat erabiliz. LAMB ostatatzea eta ereduak ostatatzea erabaki bereiziak dira; egin biak esplizitu.

[Pribatutasuna, DBEO eta instituzioaren kontrola →](/eu/privacy/)

## Instituzio batek zer eskain dezakeen {#what-an-institution-can-provide}

| Beharra | LAMBen ekarpena | Zure instituzioak erabakitzen duena |
|---|---|---|
| Hezitzaileek ikastaro bakoitzerako laguntzaileak behar dituzte | Jarraibideetarako, materialetarako eta probetarako interfaze bat | Nork sortzen dituen laguntzaileak, zein iturri onartzen diren eta nola berrikusten den kalitatea |
| Ikasleek beren ikastaroan sarbidea behar dute | LMS integrazio-bideak | Onartutako LMS/LTI konfigurazioa, matrikulazioa eta laguntza |
| Taldeek AA zerbitzuak aukeratzeko aukera behar dute | Eredu-konexio konfiguragarriak | Tokiko edo kanpoko hornitzaileak, onetsitako datuak, gastua eta zerbitzu-hitzarmenak |
| Ikasleek beren tresnetarako ereduetarako sarbidea behar dute | LLM access jarduerak: mugak, ordutegiak eta erabilera-erregistroak dituzten gako pertsonalak | Zein eredu, zenbat token irakasle eta ikasle bakoitzeko, eta noiz |
| Administratzaileek kudeatutako zerbitzu bat behar dute | Erakundeen eta erabiltzaileen administrazioa | Ostatatzea, babeskopiak, monitorizazioa, eguneraketak eta jardunaren ardura |
| Berritzaileek abiapuntu bat behar dute | API publikoa eta hezkuntza-tresnetarako baliabideak | Aplikazio bakoitzaren esparrua, hedapen-erantzukizuna eta onarpena |

Gaitasunak instalatutako bertsioaren arabera aldatzen dira. Ikusi [erabilgarritasuna](/eu/availability/) erakustaldi bat hedapen-konpromiso gisa hartu aurretik.

## Hasi mugatutako pilotu-proba batekin {#begin-with-a-bounded-pilot}

Aukeratu ikastaro bat, irakasle-talde txiki bat eta ikaskuntza-helburu argi bat. Izendatu arduradun akademikoa, LMSaren kontaktua eta sistema-operadorea. Adostu zein datu erabil daitezkeen, nola ordainduko diren ereduen kostuak eta nola informatuko zaien ikasleei.

Ikasleak gonbidatu aurretik, probatu bide osoa: irakasleen sarbidea, dokumentuen prestaketa, laguntzailearen portaera, ikaslearen abiaraztea eta laguntza. Jarduera batek kalifikazio bat itzultzen duenean, probatu erakutsitako eskala eta kalifikazio-liburuko emaitza, baita konexio teknikoa ere.

Ebaluatu pilotu-proba benetan erantzun ditzakezun galderekin: Laguntzaileak lagundu al zuen hautatutako zereginean? Zein erantzunek huts egin zuten? Irakasleak arazoa zuzendu ahal izan zuen? Zerbitzua mantentzeko eta laguntzeko modukoa izan zen? Erabilera-zenbaketek berek ez dute ikaskuntza-onurarik frogatzen.

## Pribatutasuna hedapen-erabakia da {#privacy-is-a-deployment-decision}

LAMB norberak ostatatzeak ez du berez eredu-eskaera guztiak campusean gordetzen. Kanpoko sorkuntza- eta embedding-hornitzaileek bidalitako edukia trata dezakete. Elkarrizketetarako sarbideak eta haien atxikipenak ere instituzio-politika esplizitu bat behar dute.
